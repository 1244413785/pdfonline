# PDF智能合并工具

一个功能强大的PDF合并工具，支持多文件上传、自定义分配比例和批量生成。

## 功能特点

- 📄 支持多PDF文件上传
- ⚙️ 可自定义每个文件的分配比例
- 🔄 批量生成合并文件
- 🎨 现代化美观的界面
- 📦 自动打包多份文件为ZIP

## 使用示例

假设你有：
- 文件A：30页
- 文件B：60页
- 文件C：30页

设置：
- 文件A：每份1页
- 文件B：每份2页
- 文件C：每份1页
- 生成份数：30

结果：生成30份合并PDF，每份包含1页A + 2页B + 1页C

## 安装步骤

1. 安装Python依赖：
```bash
pip install -r requirements.txt
```

2. 运行服务器：
   - Windows用户：双击 `start.bat` 文件
   - 或使用命令行：
```bash
python app.py
```

3. 打开浏览器访问：
```
http://localhost:5000
```

服务器启动后，会自动在浏览器中打开主页面。

## 使用说明

1. **上传文件**：点击上传区域或拖拽PDF文件
2. **配置比例**：为每个文件设置每份合并文件包含的页数
3. **设置份数**：输入要生成的合并文件数量
4. **开始合并**：点击"开始合并"按钮，等待处理完成
5. **下载文件**：处理完成后会自动下载（多份文件会打包为ZIP）

## 技术栈

- 后端：Flask + PyPDF
- 前端：原生HTML/CSS/JavaScript
- 文件处理：pypdf库

## 注意事项

- 确保上传的PDF文件格式正确
- 分配的页数不能超过文件总页数
- 建议在合并大量文件时耐心等待
